⚡ Trucos para Diferenciar en Java

🟦 CLASE Es el molde general. Siempre lleva la palabra clave class Nombre.
🟨 ATRIBUTO Variables declaradas dentro de la clase pero fuera de cualquier método (ej. private String marca;). No llevan paréntesis.
🟪 CONSTRUCTOR Se llama EXACTAMENTE igual que la Clase, lleva paréntesis (...) y NUNCA tiene tipo de retorno (ni siquiera void).
🟩 MÉTODO Lleva paréntesis (...) y SIEMPRE tiene tipo de retorno antes de su nombre (void, String, int, boolean...).
🟧 PARÁMETRO (Extra) Variables declaradas dentro de los paréntesis de un constructor o método: (String ma, String mo).
